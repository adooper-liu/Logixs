# ADR-013：建立可出运供给池作为正式业务缓冲层

## 状态

已确认。

## 背景

采购订单、供应商承诺、生产完成和正式可备货是不同事实。出运计划需要提前规划未来供给，同时又不能把未完成质检或合规校验的数量误认为正式可用库存。

## 决策

在采购履约与出运计划之间建立“可出运供给池”。供给池保存来源、身份、数量、时间窗、包装、生产、质检、合规、风险和预占情况。

质检未完成的供给可以参与出运预排，但不能正式释放备货。出运计划可以预占未来供给，但必须显示未满足条件、预测兑现时间及风险。预占不改变质量、合规或库存事实。

## 影响

- 采购履约和出运计划通过稳定业务对象交接。
- 计划人员可以同时看到未来供给和正式可释放供给。
- 供给预占、正式分配、备货、装箱和实际出运数量分别追踪。
