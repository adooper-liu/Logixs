# ADR-012：补货决策与执行计划分离

## 状态

已确认。

## 背景

跨境电商缺货并不必然需要新增采购。库存调拨、跨渠道再分配、供应商加急或运输加急可能以更低成本和更快速度解决需求。将补货建议直接转为采购订单会放大库存和现金风险。

## 决策

补货系统先形成净需求和补货建议，经授权人员确认后形成补货决策。一个补货决策可以拆分为采购计划、调拨计划和加急需求等多个执行方案。

采购可以合并多个补货需求，但必须保留来源及数量分摊。采购订单必须追溯补货决策、产品开发、备件需求或经批准的例外原因。

## 影响

- 建议不直接产生不可撤销订单。
- 补货工作台需要比较缺货、库存、利润、现金、时效和风险。
- 从需求到采购、调拨和出运必须保持数量守恒和来源追溯。
