## 地位

- 本目录是**必读基线**，不是业务权威。业务权威仍是本目录之外的 `doc/`、`doc/adr/` 与已批准契约；聊天结论只有经负责人确认并写回这些权威后才能进入实现。
- 原文中标为“已定”“已确认”的内容，必须核对是否有负责人原话确认；无法证实的一律按“候选”处理。`全局.md` 已指出部分结论“没有负责人原话确认，却在对话里被记成了已定”。
- 原文引用的行号、文件状态与画布路径记录的是当时快照，可能已漂移；引用前须对照当前仓库。

## 使用纪律

执行规则见 `AGENTS.md` §1.2.1 第 13 条与 §2。简述：智慧开启和建 brief 必须从本目录对应文件出发，在其上逐条确认、修正或补强，
不得另起炉灶、静默丢弃或偏离；每项变化写明依据。原文修订只能追加并注明日期、依据与负责人确认，不覆盖原句。
