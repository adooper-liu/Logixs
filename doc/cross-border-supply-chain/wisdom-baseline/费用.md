- 下游负责：财务系统执行付款并返回支付事实；经营分析消费已核定、已分摊成本；物流岗位根据费用反馈改善执行，但费用台不得改写物流事实。

**结果指标与最低保障指标的区分**

结果指标应直接量化损失：

- 已支付后确认的重复、无依据或错误收费金额/总支付金额，目标下降。
- 因逾期失去争议权或无法追回的金额与笔数，目标下降。
- 关账后新增或冲回的未应计、错分摊费用金额，目标下降。
- 辅助指标：从账单收到到“付款就绪或已争议”的周期、截止日前完成率；它们不能单独证明经营成功。

真实验收至少需要同一业务链的一套合同/费率、供应商账单、生命周期证据、内部审核、分摊、请款、支付或贷项通知，以及一例重复/错账或争议样本。单个正常样本不能证明总体损失下降。

最低保障指标另列：跨租户越权为零；已核定金额均可追溯到来源和版本；未知币种、费率和时间不得静默默认；受监管范围按适用规则保留证据和期限。这些只能守底线，不能算业务收益。

**2～3 个互斥的业务聚焦方案**

1. **方案 A：账单核验与争议止损，推荐。** 岗位为费用结算专员；核心结果是付款前形成可支付核定或有效争议。收益最接近现金损失，样本证据也最强。成本是需要补齐合同、账单、审核与回执样本。风险是若真实主要痛点发生在账单前，止损会偏晚。可逆，可在首闭环后扩展预防和月结。
2. **方案 B：超期费用事前预防。** 岗位为物流费用控制/运营人员；在免费期临界前把费用暴露交给提柜、还箱责任方处理。收益是直接避免 Demurrage/Detention/Storage。成本是需要可靠合同规则和执行归因。风险是主要动作实际属于提柜、还箱台，容易重新形成“费用控制面主导物流”。适合作为首个损失被真实数据证明主要是超期费时采用。
3. **方案 C：月结与成本完整性。** 岗位为财务成本会计；核心结果是截止日前完成应计、分摊和关账。收益是减少关账调整和利润失真。成本是强依赖财务系统和会计口径。风险是弱化付款前错账止损，并与财务系统边界重叠。适用于真实损失主要来自成本迟报，而不是供应商错账时。

**推荐方案及不成立条件**

推荐方案 A，因为它与权威中的“核费、分摊、请款和结算”最一致，又把控制面降为支撑。

两个反事实结论：

1. 没有统一控制面时，该岗位仍必须用合同、账单、作业证据和人工表格决定“付多少、分给谁、还是争议”，所以控制面不是存在理由。
2. 控制面、权限、状态和证据体系全部完美，但错付、失权和成本失真没有下降时，这台工作台不算成功。

推荐不成立的条件：真实样本证明主要损失是账单前可避免的超期费，应改选 B；或主要损失是月结迟报和成本失真，应改选 C。

**费用计算与口径**

**核心业务目的**

由物流费用结算负责人对货柜相关费用端到端负责：

> 在费用可避免阶段推动减损，在账单阶段完成核定或争议，在期末完成分摊与关账，并持续取得支付、贷项、退款或争议结论，使最终成本真实、及时、可解释。

**优先损失**

3. 未应计、迟入账或错误分摊造成的关账调整，以及柜、订单、SKU、国家成本和毛利失真。

6. 超期费用：Demurrage、Detention、Storage及合同明确存在的组合 D&D。

对账辅助表不是费用类型。修箱费、污箱费待真实闭环样本确认；罚款、仓租、平台费、广告费等不进入当前范围。

这扩大了旧原则中“仅超期费和海运费核对”的范围，正式写回时必须消除冲突。[PRINCIPLES.md (line 208)](D:/Logixs/docs/product/PRINCIPLES.md:208)

**费用项目与计算口径**

采用“稳定家族＋受控版本化费目目录”：

- 保留供应商原始费目名称，但必须映射到受控费目。
- 未知费目不得自动归类、计算或付款。
- 每个费目逐项定义业务含义、收费方、责任方、司法辖区、适用合同、计费对象、服务期间、单位、数量来源、价格来源、计算公式、免费期、阶梯、最低/封顶、附加/豁免、税制、币种、汇率、舍入、分摊基础、核验凭证及争议依据。
- 商业服务费和超期费由费用域按适用合同及业务事实计算。
- 关税、VAT引用清关权威结果；付款和财务汇率引用财务权威。
- 缺少权威依据时明确“无法核定”，不得使用历史平均、账单金额或系统默认值补空。

**金额语义**

九段事实必须分轨：

```
合同/标准 → 预计 → 应计 → 账单 → 内部核定 → 分摊 → 请款 → 支付 → 贷项/退款/追回
```

任何后续金额都不得覆盖前一阶段。争议金额和争议结论独立保留。

**分摊政策**

- 能直接归属 SKU、订单、货柜或申报行的费用不再分摊。
- 共同费用逐费目选择体积、重量、数量、货值、柜位或经批准比例。
- 关税保持 SKU/HS Code直接归属。
- 海运费及柜级超期费先归属货柜，再按该柜实际装载对象分摊。
- 分摊必须保留原金额、规则版本和尾差承担方。
- 人工自由分摊仅作为有理由、有审计的例外。

**差异与关闭**

采用风险分层容差：

- 重复账单、责任方错误、缺证、未知费目、币种错误不得自动通过。
- 纯数值差异可按费目配置经真实样本批准的绝对值、比例或舍入容差。
- 容差内可匹配但保留差额；容差外必须核定或争议。
- 实际容差数值仍未知，不得由 AI 设定。

分别定义：

- 期间可关账：预期费用均已应计，或作为有金额、原因、责任人的待定事项披露。
- 最终结清：已经付款、贷项、退款、豁免，或争议取得最终结论。
- 请款提交、争议发起、接口成功均不等于最终结清。
- 更正使用冲正、贷项或追加调整，不删除原核定、分摊及支付事实。

**结果指标**

- 已实现避免费用金额/对应风险暴露金额。
- 已拒付、贷项或追回金额/账单金额。
- 因超过合同或法定期限失去争议权的金额。
- 关账后新增、冲回或重新分摊金额/当期物流费用。
- 按柜、TEU、SKU或运输批次归一后的费用变化。
- 账单到核定、争议到结论周期及首次核验通过率只作诊断指标。

多币种分别报告；只有具备权威汇率、日期和用途时才能转换汇总。

**真实样本要求**

六个费用家族分别至少需要一套脱敏闭环证据：

- 生效合同、报价、费率表、监管依据或税单。
- 原始账单和费用行。
- 对应货柜、提单、SKU、服务期间与实际业务事实。
- 内部核定、差异及争议说明。
- 分摊依据、计算过程和尾差处理。
- 请款以及支付、贷项、退款、豁免或争议结果。

样本集还必须覆盖一次真实减损、错账或重复账、争议/贷项、跨期调整。超期费逐项验证起止事件、免费期、日历、首尾日、阶梯、暂停/豁免和收费主体。

**仍未知事项**

- 企业内部正式岗位名称与人员归属。
- 六个家族的完整真实费目清单。
- 各司法辖区税费规则和可抵扣处理。
- 合同级公式、费率、免费期、容差及争议期限。
- 分摊基础在各费目上的具体选择。
- 当前损失金额、频率和历史基线。
- 是否存在适用的组合 D&D、修箱费和污箱费闭环样本。

**主要风险**

- 把供应商账单当成事实，失去独立核费能力。
- 把关税/VAT重算放进费用域，形成法律事实双重权威。
- 以通用费用行、自由文本或万能公式抹平不同粒度。
- 把争议发起金额、预算差异或预计节省冒充真实收益。
- 用单柜正常样本确定全球费率、期限、税法或容差。
- 控制面完整但可避免费用、错付和关账调整没有下降。

Codex 在此退出前置决策对话，不进入字段、状态、权限、契约、算法、UI或实现。







费用结算这一台定得最细，业务口径的质量也最高。九段金额分开记录、按费用家族各自认定计算依据、按风险分层设容差、把"期间可关账"和"最终结清"分开，这些都可以直接写回。

不过有三个跨台问题，会直接影响前面各台的指标能否成立：

- "可避免费用"在提柜、送仓、卸柜、还箱和费用五台里都有人在算，有重复计数的风险；
- 费用范围只覆盖进口侧，订舱台的运费指标没有承接方；
- 核定和请款都由同一个负责人完成，缺少职责分离。

## 已核实的事实

- **旧原则确实限定了费用范围。** `PRINCIPLES.md` 第 211 行写着"其他费用种类（海运费核对除外）……如需纳入另走评审"。所以纳入六个费用家族（S1）是一次正式的范围扩大，要按这一行的要求走评审，并改写这一行，不能只在费用台的规格里另写一份。
- **样本 013 只覆盖加拿大进口单柜。** 文件开头写的是"适用范围：加拿大进口单柜样本；不得外推"，状态是"待费用负责人确认"。六个家族都是用这一份样本证明的。

## 需要 Claude 处理的问题

1. **可避免费用会在五台被重复计算。**
   - 提柜（M1 指标）、送仓（L1）、卸柜（M1）、还箱（M1）都把"每柜可避免损失"列为自己的结果指标；
   - 费用台又把"已实现避免费用金额"列为结果指标。

   同一笔滞港费的减少，可能被提柜和费用台各算一次。建议写回时定一条跨台规则：金额事实只由费用台记一份，按原因归到各执行台；各执行台的损失指标从这份数据里取，不自己另算。这也符合 CA1 的边界：费用台负责核验和分摊，执行台负责采取动作。

2. **费用范围只有进口侧，出口侧费用没有着落。** 六个家族里只有海运费可能同时属于出口和进口，其余都是进口目的地费用。前几轮新增的出口侧工作台都会产生费用：
   - 订舱台的商业指标"确认报价对比最终核定费用"；
   - 出口报关的报关费；
   - 出口端的拖车和装箱费用。

   这些现在都不在范围里。我上次提过"出口运费是否属于费用台"，这一轮仍然没有回答。需要负责人决定：是把出口侧费用列为待定的候选家族，还是明确不纳入，由订舱台的指标另外取数。

3. **税费偏差到底算哪一台。** CA1 规定关税和 VAT 的专业事实属于清关域，费用台只引用和分摊。这正好回答了我在进口清关那一轮提出的问题：清关台"税费准确优先"策略下的税费偏差、清关后更正、多缴和补税指标，归清关台。费用台只记分摊和支付结果，不再算一次税费偏差。写回时，两台的文字要互相引用。

4. **金额相关的动作缺少职责分离。** R1 规定一个负责人负责核定、发起争议，并提交请款。按 AGENTS 第 1.2 节第 8 条，金额费用属于高风险。行业常见的内部控制做法是：超过一定金额的核定或请款，由另一个人审批，同一个人不能既认定金额又批准付款。这只是行业候选，我没有在仓库里找到相关的权威。但对话完全没有讨论它，至少应作为待负责人定案的事项列出，并写明审批阈值需要真实样本支撑。

5. **超期费口径要从候选升为正式权威。** 海运那一轮已经定了：滞港费、滞箱费、堆存费分别计算期限，最晚提柜日和最晚还箱日取各自最早的期限；期限提前时，原交接失效。费用台现在又补充了按天逐日计费的金额计算规则。两部分都依赖 `FEE_DEMURRAGE.md`，而这份文档目前仍标着"候选 v0.3"。写回时应把它整体升为正式权威，期限部分和金额部分各自归属清楚。已完成的 brief `p6-overdue-lfd-deadlines` 和 `p6-overdue-accrual` 不追溯改写，但要按新口径逐项对照，找出差距。

6. **样本门禁 RS1 要按法域分开写清楚。** 样本 013 只能证明加拿大一个法域。关税、VAT、清关费都随法域变化，"每个家族至少一套样本"实际应该是"每个家族在每个启用的法域至少一套"，和出口报关那一轮"逐国验证、逐国启用"的思路一致。否则加拿大的样本就会被当成全局口径。

7. **付款和汇率依赖外部财务系统。** 费用台要回收支付、贷项和汇率等事实，财务系统是外部来源。按 AGENTS 第 10 节和 ADR-007，接入财务系统需要端口和适配器、超时和错误处理策略，财务数据也要先作为证据候选。首片在财务系统接入之前，只能人工登记付款回执，并保留回执原件。

## 可以直接写回的部分

- 唯一结果：事前减损、账单核定或争议、期末分摊和结清，三段不能各自宣称完成。
- 九段金额事实分开记录，后一段不覆盖前一段（AM1）。
- 按费用家族各自认定计算权威；缺依据时标记为"无法核定"，不用账单金额、历史平均或默认值补空（BP1）。
- 稳定的费用家族，加上受控、有版本的费目目录，同时保留供应商原始名称（FI1）。
- 能直接归属的费用不分摊，分摊要留下尾差承担方（AL1）。
- 重复账单、缺证、未知费目永远不能自动通过（DV1）。
- 期间可关账和最终结清分开；请款提交和争议发起都不算结清（CL1）。
- 多币种分别报告，只有存在权威汇率时才转换汇总。

## 跨台事项更新

- 可避免费用只由费用台记一份，按原因归到各台，各台指标从这里取数，不重复计算；
- 出口侧费用（订舱运费、出口报关费、出口拖车）是否纳入，需要负责人决定；
- 税费偏差指标归进口清关，费用台只记分摊和支付；
- 超期费的期限口径（海运那一轮）和金额口径（这一轮）合并，把 `FEE_DEMURRAGE.md` 升为正式权威；
- 金额动作的职责分离和审批阈值，待负责人定案。
