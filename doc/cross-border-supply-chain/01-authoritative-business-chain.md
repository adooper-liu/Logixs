# 权威业务链

## 目的与范围

本文定义跨境电商从市场信号到备货释放的权威业务链，明确各阶段的业务结果、责任边界及事实等级。它不规定数据库表、接口字段或技术状态码。

跨境电商的上游链路不能简单理解为“产品开发完成后下单采购”。一个SKU是否值得补货，既取决于销售趋势，也取决于广告投放、平台活动、库存分布、海运周期、目标国合规、资金占用和退货表现。同样，供应商是否可用，也不能只看含税单价，还要看实际生产工厂、稳定产能、质量、交期、包装效率、集货距离和目标市场资格。

因此，本业务链的重点不是把部门现有表格依次搬到系统，而是让每一个经营判断都能够说明：判断基于什么信息、由谁确认、形成什么承诺、怎样影响后续计划，以及最终结果是否验证了当时的判断。

## 总体业务链

```text
市场与经营信号
-> 选品立项
-> 产品开发与NPI
-> 产品、物料、BOM、SKU、Listing建档
-> 寻源项目
-> 供应商准入、询报价、打样与定点
-> 需求预测
-> 库存策略与补货计算
-> 补货决策
-> 采购计划
-> 采购订单与供应商承诺
-> 生产、验货与整改
-> 可出运供给池
-> 出运计划
-> 国家、渠道与仓库分配
-> 港口及整柜/拼柜方案
-> 备货单释放
-> 既有备货、装箱和出运生命周期
```

## 阶段定义

| 阶段           | 核心问题                                 | 完成结果                                   |
| -------------- | ---------------------------------------- | ------------------------------------------ |
| 市场与经营信号 | 市场是否存在稳定、可盈利的需求           | 可追溯的机会、销量、竞品、流量和客户反馈   |
| 选品立项       | 是否值得投入开发和供应链资源             | 获批的产品机会及目标市场、渠道和成本区间   |
| 产品开发与NPI  | 如何将机会转化为可生产、可合规销售的产品 | 受控的产品规格、物料、BOM和验证结论        |
| 商业化建档     | 产品如何在特定国家和渠道销售             | SKU及其Listing、包装、条码和市场适用关系   |
| 供应链寻源     | 由谁以什么条件稳定供应                   | 获批的供应关系、价格、产能、交期和主备方案 |
| 需求与补货     | 何时向哪个库存节点补多少货               | 经批准的采购、调拨或加急执行需求           |
| 采购与履约     | 供应商能否按要求兑现供给                 | 书面承诺及后续生产、检验和可用数量事实     |
| 可出运供给池   | 哪些供给具备进入出运规划的条件           | 可识别、可追溯、带风险等级的供给批次       |
| 出运计划与分仓 | 货物发往哪里并如何组织运输               | 版本化的国别、渠道、仓库、港口和装柜方案   |
| 备货释放       | 哪些货物正式进入备货执行                 | 关联计划版本和供给来源的备货单             |

## 从市场经营到供应链执行

### 市场与经营信号

需求不只来自客户订单，还来自Amazon、Walmart、eBay等平台销售，独立站、线下零售、国家销售计划、广告和促销、新品首发、平台补货建议以及海外仓调拨需求。系统应保留信号来源、观察周期和数据时点，避免把短期流量峰值误认为稳定需求。

运营可以提出新品机会、活动增量或加快补货的判断，但这些首先是经营输入，需要经过产品、供应链、利润和风险评估，才能进入批准需求。

### 选品与产品组合

选品不是寻找一个销量大的链接，而是确认目标客户、使用场景、价格带、竞争优势和可持续利润。产品创新通常沿两条路线展开：

- 在稳定需求上做出“更便宜、更好用、更耐用、更高档”等改进。
- 将已有能力带入新市场、新渠道、新场景或新人群。

建议采用“机会池 -> 商业论证 -> 评审立项”。评审既看市场规模、搜索趋势和竞品销量，也要看评价痛点、广告竞争、平台费用、包装体积、退货风险、合规门槛、知识产权、供应成熟度、目标到岸成本和退出条件。

单品机会还要放回产品组合中判断：它是否补齐现有系列，是否蚕食已有SKU，是否可以共用物料、模具和供应商，是否形成高低价格带，是否带来配件或耗材复购，以及是否增加过多长尾库存。

### 产品开发与NPI

立项后进入新品导入过程。建议采用明确阶段门：

```text
机会批准
-> 产品立项
-> 需求冻结
-> 方案与供应商确定
-> 样品验证
-> 合规验证
-> 包装及运输验证
-> 成本冻结
-> 小批试产
-> 上市批准
-> 首批采购
-> 上市后复盘
```

每个阶段都要说明进入条件、交付物、负责人和退出条件。跨境电商还要专门验证平台包装和条码、跌落与振动、超大件费用、平台仓入库限制、多语言说明书、目标国认证和标签、Listing资料以及备件和退货处理。

开发过程中的样品、测试和版本变化必须保留，不能只留下最终成品资料，否则后续无法解释质量问题、成本变化和供应商替代。

### 寻源与供应方案

寻源回答的不是“联系人是谁”，而是“谁能在什么约束下可靠供应”。一次完整寻源从需求版本出发，经历候选发现、能力调查、询报价、打样、测试、验厂、商务比较、定点和量产批准。

最终形成的供应方案应包含主供、备供、有效价格、MOQ、包装倍数、产能、交期、目标市场资格和切换条件。没有备供的关键物料不是普通完成状态，而是一项需要持续治理的经营风险。

### 需求、库存与补货

销量预测只回答“可能卖多少”，补货还要回答：现有库存和在途能否及时到达，是否来得及生产和运输，补这么多是否会造成过量库存，现金和利润是否允许。因此补货以净需求为起点，而不是直接把预测量转成采购量。

当某海外仓预计缺货时，应先比较同网络调拨、跨仓调拨、跨渠道再分配、在途改配、供应商加急和新增采购。采购只是可能的执行方案之一。

### 采购履约与可出运供给

采购订单建立了商业责任，但不表示货物已经可以出运。供应商确认、生产完成、检验通过、包装数据完整和目标市场合规满足，分别代表不同阶段。

“可出运供给池”把这些阶段统一呈现给出运计划。计划人员可以提前看到未来供给并进行预排，但必须清楚区分尚未质检、预计完成、已经释放和已经被其他计划占用的数量。

### 出运计划与分仓

出运计划先确定货物服务的国家和渠道，再根据库存覆盖、销售窗口、仓容和履约要求分配仓库，之后选择目的港并组织整柜或拼柜。不能先为了凑柜决定目的地，再倒推业务需求。

分仓一旦改变国家、渠道或仓库，就可能同时改变合规、标签、单证、税务、港口和到仓时间。因此这类变化必须形成新计划版本，而不是直接修改原记录。

## 计划层次为什么不能合并

| 计划     | 回答的问题                               |
| -------- | ---------------------------------------- |
| 需求计划 | 预计在什么市场、渠道和时间卖多少         |
| 库存计划 | 各库存节点应保持多少可售库存和安全余量   |
| 供应计划 | 由哪些供应来源满足需求，存在什么缺口     |
| 补货决策 | 哪个节点何时需要补多少，选择何种执行方式 |
| 采购计划 | 何时向哪个供应商或工厂采购多少           |
| 出运计划 | 何时把哪些SKU从哪里运到哪里              |
| 分仓计划 | 每个国家、渠道和仓库分配多少             |
| 组柜计划 | 哪些供给一起进入哪个柜次                 |
| 备货单   | 供应商现在需要准备和交付哪些货           |

后一层计划可以引用和分解前一层计划，但不能反向覆盖前一层的历史判断。

## 闭环反馈

链路并不在备货或出运时结束。后续实际销售、评价、退货、费用、交期、海运延误、清关和入仓数据要反向校准选品判断、供应商表现、端到端提前期、安全库存以及分仓和运输策略。

模型可以提出参数调整建议，但不能因为一次异常自动重写长期规则。异常是否纳入常态基线，需要业务人员审核。

## 四类事实

| 类型 | 定义                               | 典型内容                           | 使用边界                       |
| ---- | ---------------------------------- | ---------------------------------- | ------------------------------ |
| 信号 | 尚未被责任方正式确认的输入         | 销量趋势、活动目标、供应商口头反馈 | 可用于分析，不作为执行承诺     |
| 建议 | 规则、模型、AI或人员形成的候选方案 | 补货建议、推荐供应商、调拨方案     | 经授权确认后才能转为计划或决策 |
| 承诺 | 责任方已经书面接受的责任和时间     | 采购订单、供应商确认、仓库预约     | 变更必须留痕并评估影响         |
| 实际 | 已经发生且具有证据的业务事实       | 完工、验货、装箱、离港、入仓       | 不得被计划或预测覆盖           |

供应商口头承诺属于信号；只有可追溯的书面确认才构成供应承诺。

## 计划时间围栏

- 冻结区：已经下单、排产、订舱、集货或临近执行，系统不得自动改变。
- 半冻结区：允许调整，但必须展示影响并经过授权审批。
- 灵活区：允许根据需求、库存和供应变化重新计算。

所有调整形成新计划版本，保留变更原因、影响范围、批准人及上下游处理结果。

## 业务例外

- 无备供的关键物料可以在风险豁免下运行，但必须指定责任人和整改期限。
- 战略新品可以突破常规试销量，但必须明确预算、风险承担人和退出条件。
- 紧急采购可以先行处理，但必须记录例外原因、审批人并限期补齐需求关联。
- 质检未完成的供给可以参与出运预排，但不能正式释放备货。

## 验收标准

1. 任一采购、供给批次、出运分配和备货单均可追溯至需求来源。
2. 用户能够识别当前信息是信号、建议、承诺还是实际。
3. 计划变化不会覆盖历史版本或已发生事实。
4. 备货释放前能够确认供给身份、数量、质量、合规和目的地要求。
