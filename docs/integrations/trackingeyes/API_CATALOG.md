# 云当网 API 与能力目录

> 状态：**外部供应商核验知识库（参考，待签约版本联调复核）** · 2026-09-18

采集自公开文档站快照，共 67 个接口。路径栏 `（回调）` 表示该接口是**云当网回调我方地址**的推送协议，不是我方主动调用的端点。接口 ID 用于按 `doc/{id}` 回溯原文。

## 通用契约

- 请求：token 与公司编码作为 **Query 参数**（非 `Authorization` 头），详见 [AUTH_AND_SECURITY](./AUTH_AND_SECURITY.md)。
- 响应信封：`{ code, type, message, result }`，`code=200` 为成功，`type` 取 `success|warning|error`。**`warning` 表示部分失败**，须逐条读错误码，不得整体视为成功。
- 时间：所有时间字段为字符串 `"yyyy-MM-dd HH:mm:ss"`，**无时区**，无值为空字符串 `""`。详见 [FIELD_AND_TIME_SEMANTICS](./FIELD_AND_TIME_SEMANTICS.md)。
- 三条主线：**订阅（我方调用）→ 推送（平台回调）→ 下载（我方调用，用于补拉与对账）**。绝大多数数据域都提供完整三件套，因此**不存在"无补拉接口"的可靠性降级**——这是相对飞驼的一项实质性改善。

## 12. 对 Logixs 十四站主链的覆盖

| 节点                | 覆盖 | 来源                                                   |
| ------------------- | ---- | ------------------------------------------------------ |
| 备货就绪 / 工厂装箱 | ✗    | 发货人侧，平台不覆盖                                   |
| 出运                | △    | 海运跟踪 `LOBD` 装船                                   |
| 离港                | ✓    | 海运跟踪 `DLPT`                                        |
| 海运在途            | ✓    | 海运跟踪 + 集装箱轨迹 + 船舶 AIS                       |
| 中转                | ✓    | `TSBA`/`TSDC`/`TSLB`/`TSDP` + 支线 `FD*`               |
| 清关                | △    | 报关状态、美国清关、港区查验——**按权威矩阵均为佐证级** |
| 到港                | ✓    | `BDAR` + 港区数据 + 全球码头数据                       |
| 铁路转运            | ✓    | `IRLB`/`IRDP`/`IRAR`/`IRDS` + `ERDP`/`ERAR`            |
| 提柜                | ✓    | **EIR** + `STCS` + `DGOT` + 场站数据                   |
| 送仓                | △    | 车辆 GPS/轨迹——契约明确不足以单独完成                  |
| 卸柜 / 卸空         | △    | `PDDS`/`CTUP` 目的地卸箱拆箱，仓库侧事实仍缺           |
| 还箱                | ✓    | **EIR** + `RCVE`                                       |

净收益：能实质喂上**约 6 个节点**（离港、海运在途、中转、到港、铁路转运、提柜、还箱），佐证 3 个，另有 2 个平台不覆盖。**EIR 与码头类 `GTOT`/`DGOT` 是提还箱最有价值的证据**，与 Logixs 现有 [EXTERNAL_EVENT_MAPPING](../../product/domain/EXTERNAL_EVENT_MAPPING.md) 里的 `EIR RELS YAR -> 放箱` 条目可以直接对上。

## 13. 待供应商确认

1. 普通 CT 与综合 CT 的订阅差异、计费与逐字能力清单。
2. 三个支持代码接口的返回是否会随合同变更，以及变更通知机制。
3. `/api/terminalOpTime/queryTerminalOpTime` 与 `/api/localCharge/queryOptime` 的完整字段语义。
4. 推送地址的验签协议、重试策略、超时与最大重试次数。
5. 推送是否有总体限流；分页推送（船期 500 条/页）的暂停与续传语义。
6. `timeZone` 不传时 `/shipAIS/v2/*` 的时间语义。
7. 删除动态（`deleteStatus`）的触发条件与不可逆性。
