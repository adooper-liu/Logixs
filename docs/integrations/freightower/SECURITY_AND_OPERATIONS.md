# 飞驼安全、运维与核验清单

> 状态：**外部供应商上线核验清单（候选，未完成）** · 2026-09-10

## 安全控制

- API 密钥、Token、clientId 和回调密钥只从密钥管理系统或运行环境读取，按租户隔离并支持轮换。
- Webhook 必须配置验签、时间窗和重放防护；飞驼未提供协议前不得将来源 IP 当作唯一认证手段。
- iframe URL 可能暴露 `key/clientId/billNo/containerNo`，不得写入日志、分析平台或浏览器可长期缓存位置；生产启用前须获得短期令牌或等价隔离方案。
- CBP Importer Bond 数据可能含个人/企业敏感信息，实行最小采集、字段级加密、掩码展示、访问审计和保留期删除。
- 日志仅记录追踪 ID、订阅 ID、脱敏对象号、状态和延迟，不记录完整载荷、Token、Cookie 或密钥。

## 监控与审计

至少监控调用成功率、业务拒绝率、Webhook 延迟、重复率、乱序率、未知码率、解析失败率、补拉/对账差异、死信积压和最后成功同步时间。告警须能定位租户、能力、订阅和追踪 ID。

审计链应连接：用户/系统动作、`ClientOperation`、供应商请求摘要、原始载荷哈希、同步回执、映射版本、规范事件、生命周期判定和工单/子任务变更。

## 上线前必须向飞驼确认

1. Webhook 路径配置、签名算法、重试策略、超时、IP 范围和投递唯一 ID。
2. 各接口限流、计费、SLA、数据保留期及沙箱与生产差异。
3. 中国港区推送对象/数组契约及断档后的补拉接口。
4. `/container/match` 参数优先级、EIR `yardCode` 必填规则。
5. 中国海关 GET 是否创建订阅或产生费用。
6. 美国海关全部事件码方向、撤销关系和多类 hold 聚合规则。
7. 船舶尺寸单位、历史挂靠字段、RORO 拥堵过滤及 Bond 字段拼写。
8. 港口/EIR/船公司能力覆盖的版本号、生效日期和变更通知机制。
9. iframe 是否提供短期令牌、来源限制和最小权限方案。

## 验收门槛

- 使用真实脱敏样例建立契约测试，覆盖成功、空数据、未知码、对象/数组漂移和错误响应。
- 验证重复推送、乱序、重放、预计晚于实际、撤销/更正和网络中断恢复。
- 核验任何预计、AIS 推断、供应商 `COMPLETE` 均不能推进实际主链。
- 核验 `PAS/BLR/CLR/ATP`、码头 `TMPS`、美国 `CUS+Release` 保持独立业务语义。
- 安全评审通过后才启用生产凭据和 iframe；完成对账演练及密钥轮换演练。
