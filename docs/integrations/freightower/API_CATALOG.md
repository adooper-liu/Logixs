## 港区、EIR 与中国海关

| 文档 ID     | 方法与路径                                   | 用途               | 关键约束                                                     |
| ----------- | -------------------------------------------- | ------------------ | ------------------------------------------------------------ |
| 318680551e0 | `POST /terminal/port/event/subscribe`        | 中国港区订阅       | `businessNumber/portCode/ieid` 必填                          |
| 327713989e0 | 推送                                         | 中国港区事件       | 复数字段示例却为对象，Adapter 兼容对象和数组；未说明补拉接口 |
| 318680555e0 | `POST /truck/eir/subscribe`                  | EIR 订阅           | `yardCode` 必填性与说明冲突                                  |
| 318680556e0 | `GET /truck/eir/observe/{id}`                | EIR 查询           | `COMPLETE` 仅表示供应商同步完成                              |
| 318680557e0 | `GET /terminal/cn/customs/getBlnoDeclare`    | 按提单查中国海关   | 响应称“已订阅”，GET 是否有副作用/计费待确认                  |

港区覆盖（7113262m0）和 EIR 覆盖（7132122m0）必须保存为有生效日期的 `ProviderCapability` 配置，不得硬编码。当前资料显示上海、宁波、青岛、广州港区、厦门、大连等能力并不对称，天津和部分内河/地方港口还有组合条件或定制要求。

## 其他运输方式与展示

- `508089566e0`：RORO 综合跟踪。返回伪箱号，不得建立真实 `ContainerRecord`；后续使用独立 `CargoTrackingUnit`。
- `318680522e0`、`7153627m0`：航空计划能力。UTC、查询窗口最多 10 天；作为独立航空可视化上下文，计划数据不推进实际状态。
- `7111884m0`：可视化 iframe。只能辅助展示，不能成为业务真相；正式 UI 优先使用本地规范化数据。
