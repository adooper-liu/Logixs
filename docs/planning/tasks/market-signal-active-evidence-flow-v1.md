# 任务：市场信号活跃态依据区动线

> 本文件是执行、评审与交接的唯一载体。状态只看 frontmatter。  
> 权威改版：[WORKBENCH_VISUAL_FLOW_REDESIGN](../../product/WORKBENCH_VISUAL_FLOW_REDESIGN.md) §6、§7。  
> 关闭态 Mode 已合入（`market-signal-closed-mode-ux-v1` / #81）；本片只改**活跃态**。

## 目标

经营岗在**未关闭**信号上补依据与判断时：完备度只在进度头出现一次；按钮皆动词且就近；
可从标题/已有字段预填；事实未齐时判断区锁定；警示色不大面积铺底。

## 边界 / 不做

- 不改关闭态 Mode（#81）；`voided`/`archived` 行为保持。
- 不改作废/归档/选品退回落库规则；本片以呈现与补录动线为主。
- 不发明无后端的「重开」。
- 色与主题只使用 `UI_SYSTEM` + `apps/web/src/themes/logix/tokens.css`；禁止另造 hex。
- 同一时刻仅一个任务 `coding`；建议本片在选品 Mode / NPI 退回之前先落地 P0。

## 验收

- [ ] 活跃态「待补」只出现在进度头（完备度 + 必填剩 N）；底部无状态型按钮墙
- [ ] 字段旁动作为动词：「填写市场 / 选择渠道 / 添加事实 / 填写经营判断 / 添加证据」
- [ ] 容器用 `--surface-2`；全页 `--warn` ≤1，指向当前唯一必动手项
- [ ] 可从标题/结构化字段预填市场·渠道·品类，带「已自动推导」+ 一键确认；不可靠则推荐候选不强行假填
- [ ] 事实完备度未达门槛时，经营判断区灰化锁定并有说明
- [ ] 标题为陈述句：`{短对象名} · 依据与判断`；与「尚待验证」等命名不打架
- [ ] 空证据为推荐卡 + 带入，禁止孤零「0 条」
- [ ] 相关单测 / 触及 E2E 通过；`repo:check`（令牌纪律）通过

| 业务步骤与岗位结果   | 信息产生时机/前置事实      | 操作时需要看到什么                      | 系统允许做什么               | 数据如何可靠保存与反馈     |
| -------------------- | -------------------------- | --------------------------------------- | ---------------------------- | -------------------------- |
| 看还差什么、先补哪项 | 信号活跃；缺口由服务端投影 | 进度头、唯一警示缺口、已有事实/判断摘要 | 就近补录；不可跳步写判断     | 既有写接口；刷新后缺口现算 |

## 方案（design）

1. `MarketSignalEvidencePanel` 活跃态：进度头；去掉 gap-strip 状态按钮墙；字段旁动词动作。
2. 事实→判断依赖：前端按完备度锁定；文案说明门槛（与服务端校验对齐，不发明新阈值）。
3. 预填：从信号名/已有字段推导；无法解析则推荐卡。
4. 证据区空状态三件套；`--warn` 单点。
5. 单测覆盖：无「市场待补」按钮文案、有进度头、判断锁定、预填确认。
