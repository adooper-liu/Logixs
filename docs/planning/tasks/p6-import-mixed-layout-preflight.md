# 任务：导入混合版式预检

## 目标

在创建导入批次前识别“横向产品明细后拼接纵向字段值详情”的混合工作表，明确阻断并报告疑似起始工作表行，避免把货柜详情误存为产品明细。

## 边界 / 不做

- 权威边界见 `../../../ENGINEERING_RULES.md` §4.3、`../../product/domain/IMPORT_DOMAIN_MODEL.md` 和 `../../product/domain/PRECHECK_RULES.md`。
- 本切片只做输入版式防污染，不解析纵向货柜详情，不新增数据库结构或公共契约。
- 不修改或重放已经创建的历史批次；不猜测出运数量单位，不用遗留状态或推导时间制造业务事实。

## 验收

- [x] 正常横向多产品文件继续创建批次。
- [x] 横向数据后出现连续稀疏的字段名/字段值区块时，以 `VALIDATION_LAYOUT` 在持久化前阻断。
- [x] 错误明确指出疑似混合版式及首个可识别的工作表行。
- [x] 受影响测试与 `pnpm validate` 通过。

## 方案

解析时保留工作表物理行号。以当前工作表自身的非空表头作为字段标签集合；当一个稀疏数据行包含多个表头标签，且短窗口内重复出现该形态时，判定工作表混入纵向字段值区块。采用多行证据，避免单个业务值偶然等于表头时误报。
