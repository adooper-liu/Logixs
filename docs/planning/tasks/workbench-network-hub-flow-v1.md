# 任务：业务工作台枢纽 / 管道总览动线

> 本文件是执行、评审与交接的唯一载体。状态只看 frontmatter。  
> 权威改版：[WORKBENCH_VISUAL_FLOW_REDESIGN](../../product/WORKBENCH_VISUAL_FLOW_REDESIGN.md) §0、§12。  
> **页面类型**：枢纽页（横向扫描），**不**套用详情页 §2 骨架。

## 目标

用户打开「业务工作台」总览时，3 秒内能回答「活现在主要压在哪一节、该点哪个台进去」；
五节管道以业务量自述状态；交接与阻塞标在节间连接处；支撑模块与主干分层。

## 边界 / 不做

- 不在本页做单票详情编辑。
- 不伪造在办/阻塞数字；无投影时显式空态，禁止静态假数充门面。
- 不把系统能力「可工作 / 待接通」继续作为卡面主信息（可降为角标或管理说明）。
- 色与主题只认 `UI_SYSTEM` + `themes/logix/tokens.css`。
- 串行：与详情改版片同一槽位规则。

## 验收

- [ ] 五节三态：已完成收窄降饱和 / 当前节唯一加宽高亮 / 未开始虚线置灰
- [ ] 卡面主信息为 `N 在办` + 可选 `⚠K`；说明一行灰字
- [ ] 绿色不作大面积边框；已接通仅小角标；已完成节不显示接通绿

- [ ] 支撑模块浅灰底分区，与主干分层；支撑区警示锚点唯一
