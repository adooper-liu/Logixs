# 任务：市场信号作废 / 归档（B）

> 承接 [product-initiative-return-path-v1](./product-initiative-return-path-v1.md) 切片顺序中的 **B**。
> 原则依据：`HW-D18`（见 [ROLE_WORKBENCH](../../product/ROLE_WORKBENCH_HUMAN_CENTERED_DESIGN.md)）。

## 目标

经营岗可对不再推进的市场信号执行**作废或归档**，队列不再占用「待判断 / 选品退回」等在办分组；事实可审计、可只读回看。

## 负责人定案（2026-09-28）

| 项         | 定案                                                                                                                             |
| ---------- | -------------------------------------------------------------------------------------------------------------------------------- |
| 去向       | 加法：`voided`（作废）、`archived`（归档）                                                                                       |
| 决策类型   | 加法：`void`、`archive`（经既有 `POST .../decisions`）                                                                           |
| 理由       | 必填才 `completed`；缺理由 `pending_completion` 且去向仍为在办态；理由落 `judgment_note`                                         |
| 已交接机会 | **快照内容不可变**；完成作废/归档时把该信号当前 `market_opportunity_handoff.is_current=false`（supersede），选品队列不再当作在办 |
| 终态       | `voided` / `archived` 不再接受新的经营判断（本片不做重开）                                                                       |
| 不做       | 物理删除；选品侧作废；重开                                                                                                       |

## 边界 / 不做

- 本片不做物理删除（删除另立，条件最严）。
- 不改已交接机会快照字段内容。
- 不做选品侧作废；不做重开。

## 验收

- [x] 岗位能对在办信号作废或归档；理由齐才关闭到 `voided`/`archived`
- [x] 队列可见「已作废」「已归档」；终态不可再推进判断
- [x] 完成作废/归档后，该信号当前机会交接 `is_current=false`；快照行仍在
- [x] 缺理由：保存但不关闭，信号不去终态
- [x] 幂等、版本冲突、跨租户隔离（沿用既有决策路径；终态拒绝新判断）
- [ ] 相关质量门禁按风险等级通过（待 PR CI）

## 业务与数据协同设计

| 业务步骤与岗位结果 | 信息产生时机/前置事实 | 操作时需要看到什么         | 系统允许做什么       | 数据如何可靠保存与反馈                           |
| ------------------ | --------------------- | -------------------------- | -------------------- | ------------------------------------------------ |
| 作废信号           | 信号在办或已交接/退回 | 作废理由、影响（离开在办） | 作废（理由齐才关闭） | 决策版本 + 去向 voided；当前 handoff supersede   |
| 归档信号           | 同上                  | 归档理由                   | 归档（理由齐才关闭） | 决策版本 + 去向 archived；当前 handoff supersede |
| 只读回看           | 已作废/已归档         | 理由与历史去向             | 不可再判断           | 只读                                             |
