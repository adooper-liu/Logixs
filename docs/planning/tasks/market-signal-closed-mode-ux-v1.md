# 任务：经营信号关闭态整页 Mode

> 作废/归档后页面不得再催待补。关闭是页面态，不是右侧一句文案。

## 目标

经营岗打开已作废或已归档信号时，整页切换为**关闭态**：结论条最先告知已关闭，中栏只回看，
不再出现待补按钮与催办文案；左侧关闭项降权。

## 边界 / 不做

- 本片**不支持重开**（与 void/archive B 片一致）；不造「重新打开」可点按钮。
- 不做「复制为新信号」（尚无契约）。
- 不改关闭决策落库规则；只改关闭后的呈现与允许动作集合。
- 活跃态全面四层动线重构另立；本片以关闭态自洽为硬验收。

## 验收

- [ ] 关闭态中栏无「待补录」按钮；缺口收成「关闭时 N 项未补齐」摘要
- [ ] 关闭态结论条为全页最高权重（信号名 + 已作废/已归档）
- [ ] 来源证据默认折叠，同日聚合；不可补录
- [ ] 左侧已作废/已归档列表项降饱和，不出现「仍待补 N 项，不影响先处理」催办
- [ ] 筛选切换仍清空错位选中（承接上一刀）
- [ ] 相关单测通过；本片不支持重开的文案可见

## 业务与数据协同设计

| 业务步骤与岗位结果 | 信息产生时机/前置事实  | 操作时需要看到什么                       | 系统允许做什么               | 数据如何可靠保存与反馈 |
| ------------------ | ---------------------- | ---------------------------------------- | ---------------------------- | ---------------------- |
| 回看作废/归档信号  | 信号已 voided/archived | 关闭结论、关闭时缺口摘要、只读依据与证据 | 只读回看；不可补录、不可重开 | 无新写；刷新仍关闭态   |

## 工作台避坑检查

- [x] 关闭态与活跃态形态切换，避免状态与操作打架
- [x] 结论优先于证据与团队元信息
- [x] 不摆按不动的假按钮（重开）

## 方案

1. `MarketSignalEvidencePanel` 增加 `closed`：隐藏 gap-strip 按钮，缺口摘要化，证据按日折叠。
2. `MarketSignalsWorkbench` 关闭态：顶部结论条；降权 work-context；中栏为主体；动作区只读说明。
3. `MarketSignalQueue`：voided/archived 项 muted；筛选切换 clear（已起稿）。
4. 单测覆盖关闭态无待补录按钮、有关闭摘要。
