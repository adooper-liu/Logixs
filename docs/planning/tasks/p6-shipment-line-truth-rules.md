# 任务：产品明细与时间事实目标规则

> 唯一交接载体。同一时刻仅一个进行中任务。

## 目标

根据负责人确认的真实样本，纠正“一行一柜”、数量等同箱数、状态替代实际时间、推导时间冒充实际时间以及跨系统时间无时区等错误假设，冻结下一运行时切片必须实现的目标规则。

## 边界 / 不做

- 本任务定稿领域、字段和预检目标规则，不修改 API、数据库、迁移或现有 V1 运行行为。
- 现有 V1 在产品明细尚不能持久化时继续阻断同备货单多行，避免静默丢行；该限制不得再解释为业务重复规则。
- 不根据样本数值相等推断数量单位，不根据状态补造实际时间，不替历史脏数据猜时区。
- 不修改已完成的 `p6-target-field-catalog-v1.md`。

## 验收

- [x] 备货单、产品明细、货柜与生命周期事件的关系及导入粒度明确。
- [x] `shippedQuantity` 与 `packageCount` 独立，数量单位缺失时明确失败或待确认。
- [x] 清关完成必须有实际发生时间和证据；状态声明不能单独生成事实事件。
- [x] 推导卸空时间与实际卸柜/卸空事件分离。
- [x] 跨系统时间保留原值、来源时区、UTC 标准值和来源证据。
- [x] `pnpm docs:check`、`pnpm format:check`、`pnpm repo:check`、`git diff --check` 通过。

## 方案

在现有领域单一权威文档中增量修正规则：字段目录负责字段粒度，导入模型负责聚合与事务，生命周期一致性负责时间事实，预检清单引用上述权威。运行时契约、Prisma 模型、迁移、事务写端口和 UI 单独作为下一纵向切片交付。
