# 任务：选品中栏「交接包 + 信号后补」合并投影

> 本文件是执行、评审与交接的唯一载体。状态只看 frontmatter。  
> 定案：**方案 A**（见改版规范 §13）。  
> 问题：信号交接后补齐的市场/渠道/事实等，选品中栏仍只读交接当日空快照，「随后补充」承诺落空。

## 目标

选品中栏默认展示 **交接包 ∪ 信号侧后补** 的合并视图：人能看见后补内容；  
**交接当日快照行仍不可变**；凡相对快照有后补的字段，界面标明「后补」。

## 定案口径（方案 A）

| 层           | 行为                                                                      |
| ------------ | ------------------------------------------------------------------------- |
| 快照行       | `market_opportunity_handoff` 交接当日原文不变；审计仍可读「当时交了什么」 |
| 选品默认视图 | 合并：快照字段为空/缺且信号当前已有值 → 显示信号当前值并标「后补」        |
| 仍待补       | 按**合并后**现算；已后补的码不再出现在「随交接待补」墙                    |
| 禁止         | 原地改写快照行；用假数；无权威信号读口时静默假装已齐                      |

字段范围（与交接缺口同集）：`market_code`、`channel_code`、`category_ref`、`observed_fact_summary`、`hypothesis`、`evidence_refs`（及快照已有的机会说明若适用）。

## 边界 / 不做

- 不自动「再交接」升版本（那是方案 B；本片不做）。
- 不在选品侧开放改写上游信号字段（那是方案 C）。
- 不改立项硬门槛与评审要点契约。
- 已立项 Mode 下合并视图仍只读；后补标识保留。

## 验收

- [ ] 交接时缺口为空、信号后补齐后：选品中栏显示后补值，并有「后补」标识
- [ ] 打开/导出「交接当日原文」仍可见空/旧值（审计路径明确，可折叠或次级）
- [ ] 「仍待补 / 随交接未补 N」按合并后现算，不含已后补项
- [ ] 信号无后补时行为与今一致（只显示快照）
- [ ] 跨租户不可见；权限在服务端
- [ ] 相关单测 + 触及集成/E2E；契约若加法则 drift 绿

| 业务步骤与岗位结果     | 信息产生时机/前置事实         | 操作时需要看到什么                 | 系统允许做什么     | 数据如何可靠保存与反馈   |
| ---------------------- | ----------------------------- | ---------------------------------- | ------------------ | ------------------------ |
| 选品看经营交来的依据   | 已存在 current handoff        | 合并后的市场/渠道/事实/证据        | 只读领取与评估     | 投影现算；不写快照       |
