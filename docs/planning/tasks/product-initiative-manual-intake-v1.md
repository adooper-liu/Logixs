# 任务：选品立项手工新增

> 原则依据：`HW-D17`（入口三源）。上游机会交接仍是主路径，但不是唯一开工方式。

## 目标

选品岗可在无市场机会交接时**手工开建立项工作**（线下线索、补录、老板拍板），与交接进入的对象共用同一权威校验与队列。

## 边界 / 不做

- 不得伪造「上游已 handoff」；缺信号/机会引用时显式待补。
- 不替代市场信号工作台的登记与判断。
- 不作废/删除（由信号侧 B/删除或另立立项退出片）。

## 验收（草案，解锁后细化）

- [ ] 无上游交接时可选品自建并进入待判断队列
- [ ] `origin` 可区分 manual vs handoff；校验与交接路径一致
- [ ] 刷新后可继续；权限在服务端执行
- [ ] 相关质量门禁按风险等级通过
