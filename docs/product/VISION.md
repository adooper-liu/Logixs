## 一、理念提炼（三份材料在说什么）

### 1.1 全局理念（方向）

| 项      | 内容                                                                                |
| ------- | ----------------------------------------------------------------------------------- |
| 品牌    | LogiX = Logi**stics** + s**iX**(六单元) + **X**(无限可能)；中文"乐捷行"             |
| 使命    | Logistics Made Easy & Enjoyable（让复杂物流轻松愉快）                               |
| 愿景    | 看见，才能掌控；让每个物流单元得到最好的安排；黑箱→白箱                             |
| 哲学    | "让伟大归于微小"：六单元微观原子精准 + 联动 → 网络智能                              |
| 单元    | 货柜 / 订单 / 包裹 / 库位 / 仓位 / 员工操作（+1＝全链路）                           |
| 三步曲  | 看得见 → 能理解 → 被执行（= 数据→信息→行动；贴业务标签 / 带行动钩子）               |
| 层级    | 宏观-中观-微观 可视化三层；实现层＝感知(数字孪生)·认知(分析大脑)·决策执行(协同网络) |
| 闭环    | 执行闭环(响应)→优化闭环(自学习)→预见闭环(主动干预)；价值流动链                      |
| 指标观  | 微观质量指标（货柜流转效率 / 库位价值密度 / 员工操作愉悦度…）                       |
| AI 探索 | AI 助手"小乐"；Agent/MCP 自主流程（事件触发→AI 辅助决策→内外执行）                  |

### 1.2 清关 SOP（节点的"操作灵魂"）

- 一节点（清关）就是一个**作战单元**：今日必办红灯清单 → 基础信息(维护计划日期/清关公司,GIGO) → 盯过程(单据传递断点/查验独立事件) → 做动作(附件生成打包发送) → 看结果(确认已清关/实际日期) → 懂规则(何时自动触发)。
- 启示：**每个关键节点都应套"节点操作通用模型"**，SOP 是它的一份实例。

### 1.3 运营图谱（仓储域流程与最佳实践）

- 收(清关/拖卡/卸柜/还箱/到仓) → 存(上架/库位/盘点/滞销) → 发(波次/拣货/包装/尾程) + 逆向(退件)；口诀式编码（"账动先搬…"）。
- 最佳实践方向：分区与**库位近管理**（"爆品靠近、长尾靠边"）、动线/布局、波次/补货/绩效、库位价值密度=周转×价值/空间。

## 二、节点操作通用模型（把 SOP 变成模板）

> 落点＝让工作台每个 rail 节点不再是"看状态"，而是"作战台"。

| 步     | 模型                 | 现网 SOP 实例（清关）                             | 落到系统                         |
| ------ | -------------------- | ------------------------------------------------- | -------------------------------- |
| 1 起点 | 今天必须处理什么     | 6 问：日期/状态/传递/换单/ISF/异常 → 今日红灯清单 | 每日待办(红灯)视图 + 工单        |
| 2 准备 | 基础信息先对（GIGO） | 维护计划清关日期/清关公司                         | 节点 planned 字段维护入口        |
| 3 盯   | 主动找断点           | 单据传递记录/报表 红警；查验独立事件              | 事件流/异常/预警规则             |
| 4 做   | 一键动作             | 附件打包发送(≤10MB zip, 出运+14天)                | ACTION_CATALOG 一键动作+默认载荷 |
| 5 核   | 看结果闭环           | 确认"已清关"与实际日期                            | 状态推进+审计(不只"发了邮件")    |
| 6 规则 | 知道何时自动触发     | 附件生成/定时邮件/同步/最晚清关日期               | 触发规则清单(配置)               |
