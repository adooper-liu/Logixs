# 非功能需求与指标（P0-07 / P0-08）

> 状态：**已确认（初版基线）** · v0.2 · 2026-09-04。以下数值已按业务方确认采用为初版基线；**P7 评测 / P8 容量实测前不视为终值**，校准须在本文件留痕。保留期等涉及合规方的项按 [RAID](../planning/RAID.md) 跟踪。

## 1. 可用性与可靠性

| 项 | 初版基线 | 说明 |
| --- | --- | --- |
| 生产可用性 | 99.9%（月） | 内部自用阶段可下调，多租户/外部后上调 |
| 模型不可用 | 核心导入可人工映射或明确失败关闭 | 架构验收要求，不允许错误写入 |
| 备份/恢复 | RPO ≤ 15 min、RTO ≤ 4 h | P4-07/P8 演练验证后才视为有效 |

## 2. 延迟

| 项 | 初版基线 | 说明 |
| --- | --- | --- |
| API 延迟 | p95 < 500 ms | 不含模型调用；模型调用单独计 |
| 列映射建议返回 | 每批 ≤ 20 s | 依批大小与模型预算，AI Gateway 超时/降级 |
| 端到端导入（5k 行） | 上传→预检报告 ≤ 60 s | 审核耗时为人工等待，不计入 |

## 3. 容量与格式（首版默认上限）

| 项 | 默认上限 | 备注 |
| --- | --- | --- |
| 文件格式 | `.xlsx` / `.xls` / `.csv`，支持多 Sheet | 首个闭环即支持 |
| 单文件行数 | ≤ 5,000 行 | 超出走确定性分块 + 抽样的最小输入策略 |
| 列数 | ≤ 50 列 | 多列先建模板再扩展 |
| 单文件大小 | ≤ 10 MB | 依赖上传限制与对象存储策略 |
| 并发导入批次 | ≤ 5 | 依赖 Temporal 队列容量，P8 校准 |

## 4. AI 指标（首期目标，P7 门禁口径）

阈值待 P7 用固定评测集与线上反馈确认后转正式；上线前这些值即为发布门禁依据。

| 指标 | 初版目标 | 说明 |
| --- | --- | --- |
| 字段映射 Top-1 准确率 | ≥ 95% | 逐字段评测 |
| 关键字段漏提率 | ≤ 2% | 关键字段：编号/日期/数量/金额/币种等 |
| 人工修改率 | ≤ 15% | 越高说明建议质量越低 |
| 错误写入率 | 0 | 人工确认 + 确定性校验 + 对账，架构硬约束 |
| 映射建议延迟 | ≤ 20 s/批 | 见 §2 |
| 单任务（批）AI 成本 | 见预算（RAID 跟踪） | 按 Token 与模型路由核算，超限走降级 |

## 5. 数据保留期（初版；合规方确认前有效）

| 数据 | 保留期 | 说明 |
| --- | --- | --- |
| 原始导入文件 | ≥ 90 天 | 供纠纷与重放 |
| 导入批次与逐行结果 | ≥ 2 年 | 审计与对账 |
| AI 执行元数据/观测 | 依 Langfuse 保留与数据驻留策略 | 敏感载荷不得无期限留存 |
| 审计日志 | 防篡改存储，保留按合规 | P5-09 |

## 6. 明确不做（与容量相关）

- 首版不做：万行流式导入、复杂自由版式识别、高并发多租户；均在“延后引入”范围（架构 §16）。
- 容量与成本终值由 P8 负载测试给出，本文件数值为初版基线。

## 7. 校准与变更

- 任何阈值调整须修改本表并记录原因、日期与负责人；未经 P7/P8 校准不得作为发布承诺引用。
- 冲突时以更严格者为准（ENGINEERING_RULES §14 例外管理）。
