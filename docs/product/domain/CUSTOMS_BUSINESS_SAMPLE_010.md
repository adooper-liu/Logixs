# 海关业务样本 010：出口商检申请与工厂装箱

> 状态：真实脱敏局部样本 · 待业务确认 · 2026-09-08
>
> 边界：本样本包含一份出境货物检验检疫申请 PDF 和一份工厂装箱工作簿。申请文件只证明商检申请资料形成，不证明已受理、已实施检验、检验合格或取得通关凭证。

## 1. 证据登记

| 证据 ID | 文档 | 结构 | 允许证明 | 不允许证明 |
|---|---|---|---|---|
| EVD-1001 | 出境货物检验检疫申请 | 1 页 | 申请及授权声明结构形成 | 商检受理、查验发生、检验合格、海关放行 |
| EVD-1002 | 工厂装箱单 | 2 个工作表 | 工厂装箱数据、装柜记录和操作要求结构形成 | 实际装箱数据正确、商检机构已采信 |

原始文件保留在仓库之外。真实主体、业务编号、商品、数量、重量、地址、人员和时间均未写入本文件。

## 2. 工作簿结构

| 工作表 | 已观察内容 | 领域落点候选 |
|---|---|---|
| 工厂装箱单 | 合同/商品、数量、箱数、毛重、体积、实际装箱汇总及装柜要求 | FactoryPackingEvidence、PackingLine、PackingSummary |
| 集装箱检查记录 | 装箱前箱体检查和检查记录 | ContainerConditionEvidence |

两个工作表均未观察到公式。页面上的合计和汇总属于静态输入，导入时必须重新计算并保留差异结果。

## 3. 领域关系

| 对象 | 关系 |
|---|---|
| InspectionApplication | 指向一组申报货物和申请主体 |
| FactoryPackingEvidence | 指向实际装箱准备/记录及商品范围 |
| ContainerConditionEvidence | 指向装箱前的箱体状况检查 |
| CustomsDeclarationCase | 只能通过明确业务引用和货物范围关联上述证据 |
| WorkOrder | 商检资料准备、提交、补件、现场检验、结果核验分别建单 |

文件名显示两份资料可能属于同一业务批次，但文件名不是权威关联键。必须使用案卷引用、货物范围、主体、时间和受控人工确认建立关联。

## 4. 状态边界

| 状态层 | 候选状态/事实 | 不得替代 |
|---|---|---|
| 资料 | application_prepared | 已提交 |
| 操作 | submission_requested/sent | 机构已受理 |
| 机构回执 | accepted/rejected/supplement_required | 检验结果 |
| 检验作业 | scheduled/in_progress | 合格结论 |
| 检验结果 | passed/failed/corrective_action | 海关放行 |
| 同步 | pending/success/failed | 商检业务裁决 |

以上状态名称均为候选。正式代码必须用真实请求、回执和结果证书样本确认。

## 5. 规则候选

| 规则 ID | 规则 | 失败处理 |
|---|---|---|
| S010-P01 | 商检申请、受理回执、检验记录和结果证书分别保存 | 申请 PDF 不生成结果事件 |
| S010-P02 | 工厂装箱数据按商品行及其适用货柜关联 | 范围不明时不得广播到整票 |
| S010-P03 | 数量、箱数、毛重和体积独立重算并与汇总对账 | 静态合计不平时进入复核 |
| S010-P04 | 箱体检查记录保存检查项、结果、操作者、发生时间和图片/附件引用 | 空白记录不得解释为检查通过 |
| S010-P05 | 商检和海关是不同权威主体及状态机 | 商检合格不直接生成海关放行 |
| S010-P06 | 文件名关联只产生匹配候选 | 必须经字段级或人工确认后绑定案卷 |
| S010-P07 | 申请提交和查询使用幂等操作及分阶段回执 | 网络成功不代表机构受理 |

## 6. 工单与管道影响

| 事实 | 工单结果 | 主链处理 |
|---|---|---|
| 申请资料形成 | 资料准备工单可完成 | 不推进海关放行 |
| 工厂装箱资料齐全 | 装箱证据工单候选完成 | 仍需对账和适用范围确认 |
| 箱体检查完成 | 箱况检查工单完成候选 | 只影响装箱准入 |
| 商检受理/补件 | 更新商检子任务并创建补件工单 | 主链保持相应节点 |
| 合格结果到达 | 经证据验证后形成商检合格候选事件 | 是否允许下一节点由生命周期守卫决定 |

## 7. 待补齐

1. 商检提交请求、技术接收、机构受理和最终结果的脱敏样本。
2. 检验检疫结果证书或不合格/整改通知。
3. 两份文件与报关案卷、货柜和商品范围的确定性关联。
4. 工厂装箱汇总与报关装箱单的数量、重量和体积对账。
5. 商检触发条件、必检商品/地区规则及人工覆盖权限。
6. 商检合格对出口报关工序和下一主链节点的具体守卫。

## 8. 对契约的贡献

本样本支持商检申请、工厂装箱、箱况检查和证据关联的结构草案。它不能锁定商检受理/结果状态码，也不能作为海关放行证据。
