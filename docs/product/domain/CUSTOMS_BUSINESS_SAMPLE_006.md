# 海关业务样本 006：英国 CDS Customs Cleared

> 状态：真实脱敏批量样本 · 待业务确认 · 2026-09-08
>
> 边界：八份 CDS Import 文档均明确显示 `Declaration status Customs Cleared`。这是当前样本库中最强的明确清关状态组，但仍不单独证明码头/承运人放行或货柜已经可提。

## 1. 批量观察

| 项目     | 观察结果                                                            |
| -------- | ------------------------------------------------------------------- |
| 样本数   | 8 票独立 CDS Import                                                 |
| 稳定标识 | 每票包含 MRN                                                        |
| 受理事实 | 每票包含 `Acceptance date/time`                                     |
| 状态事实 | 每票包含 `Declaration status Customs Cleared` 和 `Status date/time` |
| 时间关系 | 受理与清关状态时间分开；样本覆盖分钟级至隔夜完成                    |
| 业务内容 | 申报商品、税费、货柜、进口商和申报人字段                            |

真实 MRN、主体、地址、货柜号、商品、金额和时间均未写入本文件。

## 2. 领域判定

| 项目         | 判定                                                             |
| ------------ | ---------------------------------------------------------------- |
| 文档类型     | `CDS Import`                                                     |
| 原始状态     | `Customs Cleared`                                                |
| 规范语义候选 | 注册事件 `release`，context 标记英国管辖区与方向                 |
| 发生时间候选 | `Status date/time`，不得使用文档下载或系统接收时间代替           |
| 受理时间     | `Acceptance date/time`                                           |
| 适用对象     | 必须由 MRN/申报与货柜显式关联确定                                |
| 下一节点     | 仅在规范事件验证且其他必要 Hold 已解除后，才可由生命周期守卫决定 |

`Customs Cleared` 比“文档已形成”或“出现 release 字样”更明确，但文档仍需来源真实性、完整性和适用范围校验。系统不能只做字符串匹配。

| -------- | ---------------------------------------------------------------- | ------------------------------ |

## 4. 候选规范载荷

以下只是从样本提炼的字段集合，不是已定稿 DTO：

```text
jurisdiction
authority
documentType
declarationReference
rawStatusText
applicableContainerIds
acceptedAt
statusAt
evidenceId
verificationStatus
mappingRuleVersion
occurredAt
recordedAt
```

`occurredAt` 来自权威状态时间，`recordedAt` 来自系统接收时间；两者不可互相覆盖。幂等键必须覆盖管辖区、声明引用、规范事件、发生时间和适用对象，具体格式待公共契约评审。

## 5. 失败与边界场景

| 场景                      | 处理                                         |
| ------------------------- | -------------------------------------------- |
| 同一文档重复导入          | 证据和规范事件去重，不重复转移               |
| 同一 MRN 出现不同载荷     | 拒绝静默合并，进入冲突队列                   |
| 状态先于内部工单到达      | 验真后允许生命周期前进，并创建补录/对账任务  |
| 旧状态晚到                | 保留历史，不回退较新的有效裁决               |
| 解析或同步失败            | 更新 SyncRecord 并重试，不把业务事实改成失败 |
| 状态已清关但存在其他 Hold | 停留在守卫处，不宣称可提柜                   |

## 6. 待确认

1. CDS 文档的权威签发/下载渠道和真实性验证方法。
2. `Customs Cleared` 的撤销、更正及后续状态样本。
3. MRN 对货柜的精确适用范围和分批放行行为。
4. 从海关节点进入提柜节点所需的非海关 Hold 矩阵。
5. 服务商 API 的原始响应、状态码、Webhook/轮询和重试样本。

## 7. 对契约的贡献

本样本可支持英国 `Customs Cleared` 的强放行候选、acceptedAt/statusAt 分轨、批量幂等和货柜范围守卫设计。它仍须经过英国报关业务负责人确认，才能从样本候选升格为唯一公共契约。
