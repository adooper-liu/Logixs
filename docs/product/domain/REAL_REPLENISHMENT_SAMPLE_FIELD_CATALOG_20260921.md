1. `出运数量` 是 SKU 数量；`件数/箱数/PKGS` 在本样本多数是包装件数。数值恰好相同不构成单位换算规则。
2. 备货平台的毛重/体积是备货单级重复展示；报关 BOM 是 SKU 行；报关票、分提单、货柜和总提单均有各自汇总层级。
3. `价格条款=CIF` 属于商业/订舱口径，报关票 `FOB` 属于申报口径，两者可同时成立。
4. `出运日期`、`实际开船日期`、`开航日期`在本样本日期相同，但字段语义仍须分开；不能据一次相等永久合并。
5. `主备货单号`只作合并票展示。实际备货单到货柜关系由 `orderNumber → containerNumber` 分别为 `26DSC01811 → HMMU4207629`、`26DSC01812 → HMMU4956442`。
