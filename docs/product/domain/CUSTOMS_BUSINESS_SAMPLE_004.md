# 海关业务样本 004：意大利 H1 申报与关税借记

> 状态：真实脱敏批量样本 · 待业务确认 · 2026-09-08
>
> 边界：十份 H1 申报文件和三份货代关税借记单只支持申报结构、税费结构及财务计收事实。当前材料不能稳定证明海关已经放行，也不能触发主链转移。

## 1. 样本目的

用同一管辖区的批量真实单据确认 H1 申报、商品税费和货代税费借记之间的边界，并验证意大利状态文字在进入公共契约前必须完成字段级释义。

## 2. 证据登记

| 证据组 | 数量 | 文档类别 | 允许证明 | 不允许证明 |
|---|---:|---|---|---|
| EVD-401 | 10 | `DICHIARAZIONE H1 - Copia di Cortesia` | H1 申报副本已形成；包含申报引用、主体、货柜、商品行、TARIC 和税费项目 | 已受理、已放行、可提柜 |
| EVD-402 | 3 | 货代 `NOTA DEBITO` / `DIRITTI DOGANALI` | 货代向进口方计收或转付海关税费的财务事实 | 海关裁决、税款最终清算、货柜放行 |

原始文件保留在仓库之外。主体、地址、税号、货柜号、申报引用、发票号、金额和商品信息均未写入本文件。

## 3. 已观察结构

| 分组 | 已观察内容 | 领域处理 |
|---|---|---|
| 申报制度 | `H1 Z4000` | 保存管辖区、申报种类和程序代码原值 |
| 商品 | 商品行、TARIC、数量/重量和估价字段 | 按申报行保存，不把显示文本拼成状态码 |
| 税费 | `A00`、`B00`，部分单据还有其他税费代码 | 税费类型、计税基础、税率、金额和币种分开保存 |
| 状态文字 | `Stato IUT`、`CDCLRN`、`A93 Svincolo` | 当前仅为原始字段候选，等待字段和值的正式释义 |
| 页脚回执 | `Ricezione Esito`、`Ricezione Svincolo` 未见明确值 | 空白标签不能解释成已收到结果或放行 |
| 货代借记 | 海关税费借记及关联业务拆分 | 归入费用/对账证据，不归入放行证据 |

## 4. 领域判定

| 项目 | 判定 |
|---|---|
| 证据类型 | `CustomsDeclarationEvidence`、`CustomsChargeEvidence/BrokerDebitNote` 候选 |
| 权威主体 | H1 文件的签发及传输来源待登记；货代仅对其财务单据负责 |
| 可生成候选事实 | 申报副本形成、申报税费明细形成、货代税费借记形成 |
| 不可生成事件 | `customs.release.confirmed`、Hold 解除、可提柜 |
| 当前节点 | 最多支持海关申报/税费处理子阶段，不能确认主链位置 |
| 下一节点 | 不推进 |

`Svincolo` 在意大利语境中可能表达放行，但本批版式没有给出足够明确的“字段名、字段值、发生时间、适用对象”组合。不得因页面出现该词或 `A93` 就认定已放行。

## 5. 规则候选

| 规则 ID | 规则 | 失败处理 |
|---|---|---|
| S004-P01 | 状态映射键至少包含 jurisdiction、documentType、fieldPath、rawCode/rawText 和版本 | 未知组合进入复核，不按裸码映射 |
| S004-P02 | `Ricezione Esito/Svincolo` 必须有明确值和发生时间才能形成回执事实 | 空白标签不生成事件 |
| S004-P03 | H1 申报行和税费行保留原值、单位、币种与来源 | 缺失或解析歧义逐项报告 |
| S004-P04 | 货代借记单只进入费用对账 | 禁止作为生命周期守卫输入 |
| S004-P05 | 申报引用到货柜必须显式关联 | 不向未确认货柜广播状态 |
| S004-P06 | OCR 结果只是抽取候选，必须与原图和人工复核结果分层保存 | 低置信字段不得成为权威事实 |

## 6. 待确认

1. `IUT`、`CDCLRN`、`A93` 在该版 H1 输出中的准确字段和值语义。
2. `Ricezione Esito` 与 `Ricezione Svincolo` 的非空真实样例及时间字段。
3. H1 文档签发主体、获取渠道、内容哈希和适用货柜范围。
4. 权威放行回执、撤销/更正回执以及码头或承运人 Hold。
5. 货代借记与申报税费的逐票对账键和差异处理。

## 7. 对契约的贡献

本样本支持定稿申报、申报行、税费、费用证据和 OCR 复核结构；不支持定稿意大利放行码、放行证据等级或海关节点到提柜节点的转移守卫。
