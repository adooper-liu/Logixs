# 海关业务样本 002：美国进口申报资料准备

> 状态：真实脱敏样本 · 待业务确认 · 2026-09-08
>
> 消费者：customs-compliance、shipment-registry、外部证据 Adapter、契约与测试负责人。
>
> 边界：本样本证明美国进口申报资料、HTS 估价输入和特殊用途佐证之间的关系，不证明 CBP 已受理、放行、征税完成或结关。原始文件保留在仓库之外。

## 1. 样本目的

1. 验证 ISF、Sea Waybill、商业发票、装箱单、HTS 导入表和 End Use Certification 的对象关联。
2. 验证商业发票金额与 HTS 申报金额必须分开保存。
3. 验证国际运费和保险费的逐行分摊关系。
4. 验证农业用途条款只适用于明确的商品行。
5. 验证申报资料齐全仍不能生成海关放行事件。

## 4. 已确认事实

| 规则 ID | 事实 | 依据 | 处理结论 |
|---|---|---|---|
| S002-F01 | 一份 Sea Waybill、一个业务单和一个货柜可稳定关联 | EVD-201、EVD-206 | 建立 Shipment、Container 和 typed reference |
| S002-F02 | ISF 与 Sea Waybill 的货柜、封条、提单、航线可关联 | EVD-201、EVD-206 | 原值和规范化值并存 |
| S002-F03 | ISF 预计离港日与 Sea Waybill On Board Date 为同一自然日 | EVD-201、EVD-206 | 仍分别保存预计与实际/单证时间性质 |
| S002-F04 | 发票源表有 10 个唯一 SKU，数量乘单价均等于行金额 | EVD-204 | 行级算术预检通过 |
| S002-F05 | 发票 PDF 与源表声明总额一致 | EVD-202、EVD-204 | PDF 是源表展示结果，不形成第二套金额真相 |
| S002-F06 | 装箱单与 HTS 表的 SKU 数量、总数量、箱数、净重、毛重和体积一致 | EVD-203、EVD-205 | 可建立包装证据到申报行的对账 |
| S002-F07 | 发票与 HTS 表的 10 个 SKU 和数量逐项一致 | EVD-204、EVD-205 | 同一商品行可关联两个不同金额语义 |
| S002-F08 | HTS 逐行金额与商业发票逐行金额不同，但 HTS 总额等于发票声明总额 | EVD-204、EVD-205 | 保存 invoiceLineAmount 与 customsEnteredValue，不互相覆盖 |
| S002-F09 | HTS 行金额相对发票商品金额的全部增量，合计等于海运费与保险费 | EVD-204、EVD-205 | 形成国际运保费分摊规则候选 |
| S002-F10 | 发票列出的国内物流费未进入声明总额，也未进入 HTS 申报金额 | EVD-204、EVD-205 | 形成估价排除项候选，须业务/法规确认 |
| S002-F11 | End Use Certification 只覆盖一个温室类 SKU，并同时引用基础 HTS 与农业用途条款 | EVD-205、EVD-207 | 特殊条款按申报行适用，不传播到整票 |
| S002-F12 | 当前资料没有 CBP/飞驼请求、受理、放行或结关回执 | 全部证据 | 不生成海关受理或放行规范事件 |

## 5. 一致性与差异检查

| 检查 ID | 检查 | 结果 | 政策 |
|---|---|---|---|
| S002-C01 | 发票 PDF 与源表业务号、货柜、币种、总额 | 一致 | 源表为结构化输入，PDF 为不可变展示证据 |
| S002-C02 | 发票与装箱单商品集合 | 可关联 | 商品描述差异按 SKU 消歧 |
| S002-C03 | 装箱单与 HTS 包装/重量/体积合计 | 全部一致 | 保存独立来源和对账结果 |
| S002-C04 | 发票与 HTS 商品数量 | 10 行全部一致 | 数量冲突时逐行阻止 |
| S002-C05 | 发票商品金额与 HTS 申报金额 | 逐行不同、总额可对平 | 两套金额字段及计算依据分开 |
| S002-C06 | 国际运费及保险费分摊 | 增量总额可精确对平 | 分摊算法和舍入方式仍需确认 |
| S002-C07 | 国内物流费是否进入申报金额 | 未进入 | 作为待确认估价规则，不自动判错或自动排除 |
| S002-C08 | End Use 商品与 HTS 表 | SKU、基础 HTS 和农业用途条款可关联 | 仅该行进入特殊用途证据核验 |
| S002-C09 | xls 扩展名与文件内容 | 不一致，实际为 XLSX | 文件签名优先并生成格式告警 |

## 7. 预检规则候选

| 规则 ID | 规则 | 失败处理 |
|---|---|---|
| S002-P01 | 发票、装箱单、HTS 表按业务单、货柜和 SKU 显式关联 | 缺失或多义进入逐行错误 |
| S002-P02 | invoiceLineAmount 与 customsEnteredValue 使用独立定点金额字段和币种 | 禁止互相覆盖 |
| S002-P03 | 每个 HTS 申报行记录基础商品金额、分摊费用、申报金额和舍入差额 | 无计算依据时阻止自动提交 |
| S002-P04 | 国际运费、保险费和国内物流费按费用类型保存 | 禁止汇总为无类型附加费 |
| S002-P05 | 国内物流费是否计入申报金额由有版本的管辖区估价规则决定 | 无匹配规则进入业务复核 |
| S002-P06 | 特殊用途条款必须绑定具体商品行、声明文件和签署主体 | 不允许票级广播 |
| S002-P07 | HTS 格式差异先规范化再比较，同时保留原始值 | 不能因小数点位差异静默覆盖 |
| S002-P08 | xls/xlsx 按文件签名识别并保留原始扩展名 | 格式冲突显式告警 |
| S002-P09 | 单证准备事实不能产生海关受理、放行或节点转移 | 主链停留并等待权威回执 |

## 9. 对第一批契约的贡献

可用于定稿：

- 商业发票金额、费用分摊和海关申报金额的分层模型。
- InvoiceLine、PackingLine、CustomsEntryLine 和 EndUseEvidence 的关联。
- HTS 原始值、规范值、基础税则号及特殊用途条款的字段结构。
- 文件签名识别、逐行对账和金额重算预检。
- 单证准备完成但无 CBP 回执时不推进主链。

不能用于定稿：

- CBP 动作、受理、Hold、Release 和结关事件码。
- 请求/受理/终态回执 DTO。
- 放行证据等级和生命周期转移守卫。
- Webhook 幂等、重复、乱序及同步失败规则。
