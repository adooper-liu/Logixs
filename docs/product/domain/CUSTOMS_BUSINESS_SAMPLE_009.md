## 2. 已观察投影结构

| 分组 | 字段族 |
|---|---|
| 订阅基本信息 | MBL、集装箱号、是否按 MBL 订阅、订单状态/说明、结束时间、更新时间、首次获取时间、海铁联运和 3PL 标记 |
| 承运人/订舱 | 船公司名称、SCAC/代码/网站、订舱状态中英文 |
| 收货/交货地 | 标准名、原始名、时区、地点代码、经纬度、码头、预计/实际到离时间 |
| 头程船 | 船名、航次、航线代码 |
| 当前状态 | 船舶航次、货柜、状态代码、发生时间、是否已发生、地点、标准/原始描述、来源和货物位置 |
| 发生地 | 标准/原始地点、类型、经纬度、时区、预计/实际到离时间及首次获取值 |
| 路径/港区计划 | 起讫地点、运输方式、船舶航次、码头计划、开截港和船代 |
| 货柜/事件 | 箱型箱尺、封条、当前状态；ACT/EST、异常节点、来源、分单/报关引用 |
| 船舶/单证 | IMO、MMSI、船旗、运营方；装卸港 EDI、箱重、危险品、分件；VGM 重量和报文时间 |

这些字段只是界面投影目录，不等于飞驼 API 已验证 DTO。正式契约必须通过对应接口原始载荷和版本对拍。

## 3. 部分数据判定

| 观察 | 正确处理 |
|---|---|
| 基础 MBL、货柜和承运人代码有值 | 可建立待验证的业务引用 |
| 订阅状态、首次获取和更新时间为空 | 订阅/同步状态为 unknown，不默认成功或失败 |
| firstVessel、currentStatus、places 为空 | 投影标记 partial/unknown，不生成否定业务事实 |
| routes、terminalPlan 为空 | 不推断无中转、无计划或未靠港 |
| containers/status 为空 | 不删除已有 ContainerRecord，不回退主链 |
| vessel/packinglist/VGM 为空 | 分别保持 unknown；一个子投影为空不污染其他投影 |

“暂无数据”至少可能表示尚未订阅、未首次拉取、供应商未覆盖、查询键不匹配、同步失败、尚无事件或真实无数据。缺少明确的供应商响应码时，系统不能自行选择其中一种原因。

## 4. 时间与来源规则

| 规则 ID | 规则 | 失败处理 |
|---|---|---|
| S009-P01 | 预计到离、实际到离、首次获取 ETA/ETD 分列保存 | 不以新预计值覆盖实际或首见基线 |
| S009-P02 | 状态发生时间、供应商更新时间、系统接收时间和首次获取时间分离 | 乱序按业务时间与版本对账 |
| S009-P03 | 标准地点/描述与原始地点/描述并存，并记录映射版本 | 无映射时保留原值进入复核 |
| S009-P04 | 每个事件保存数据来源、预计/实际标记和是否已发生 | 预计事件不推进实际主链 |
| S009-P05 | 船舶计划或路径不能证明具体货柜已装卸 | 需要货柜级实际事件 |
| S009-P06 | 货柜、提单、分单和报关引用使用 typed reference | 不按显示字符串偶然相等合并 |

## 5. 同步和空数据状态

建议把以下状态独立保存：

| 状态层 | 示例语义 |
|---|---|
| ProviderSubscription | not_requested、requested、active、stopped、failed |
| ProviderSyncReceipt | pending、success、nodata、partial、failed |
| ProjectionCompleteness | unknown、partial、complete、stale |
| BusinessFact | 实际运输、单证或状态事件 |
| LifecycleState | 由规范事件和守卫决定 |

其中代码名称仍是候选。供应商 `NODATA` 只能改变同步结果和投影完整度，不能生成“未装船”“未到港”等否定事实，也不能清除之前已经验证的事件。

## 6. 工单和主链影响

| 场景 | 工单候选 | 主链政策 |
|---|---|---|
| 尚未订阅 | 创建/审核船公司订阅工单 | 不移动节点 |
| 首次获取长期为空 | 查询键核对、覆盖能力核查 | 保持当前事实，标记数据缺口 |
| 部分页签有值 | 部分同步对账 | 只消费已验证的实际事件 |
| NODATA 后收到事件 | 重放和历史补录 | 按 occurredAt 入历史，不伪造接收顺序 |
| 已有事件后投影变空 | 数据回退/供应商异常核查 | 不删除既有权威事实 |

## 8. 对契约的贡献

本样本支持飞驼船公司投影结构、字段级来源、部分数据、空数据和陈旧数据处理的契约草案。它不能锁定任何运输节点已发生，也不能直接推进 14 节点主链。
