# Logix UI 体系标准（UI_SYSTEM · 候选 v0.1）

> 状态：**候选 v0.1** · 2026-09-05 · 用途：全端视觉一致的**唯一 token 源**（颜色/排版/间距/形态/状态映射），代码以 CSS 变量落地。
> 取优 legacy(D:/Github/logix)：Element Plus 基础组件、运营表格/状态标签、红黄绿语义、统计卡/桑基/时间线信息模式。
> 补短 legacy：无 token、临时渐变(#667eea…)与重复裸色、无统一语义/深浅双主题 → 收敛为 品牌+中性+语义 三层变量。
> 🗣️ 白话：先定"一套油漆和标尺"，全项目都按它上色、定字号留白，界面才像同一个产品而不是各画各的。

## ① 色彩令牌（颜色就是库表值）
| 组 | 令牌 | 值(浅/暗) | 用途 |
| --- | --- | --- | --- |
| 品牌主色 | `--brand` | `#0f5fbf / #6aa4ff` | 主按钮/激活/强调；Element 主色同源 |
| 品牌浅衬 | `--brand-soft` | `#e6f0fc / #1a2c46` | 选中底/hover |
| 中性文字 | `--ink` / `--ink-soft` / `--muted` | 见 code | 标题/正文/次要 |
| 线/面 | `--line` / `--surface` / `--ground` | 见 code | 边框/卡片/页面底 |
| 语义·正常 | `--ok` / `--ok-bg` | `#178a4c/#53d68a` | 已完成/正常/放行 |
| 语义·预警 | `--warn` / `--warn-bg` | `#c07a12/#e6b15a` | 临近/待办/漂移 |
| 语义·风险 | `--risk` / `--risk-bg` | `#d64545/#ff7a7a` | 超期/扣留/红灯 |
| 语义·信息 | `--info` | 中性偏蓝 | 提示/进行中 |
| 状态·禁用 | `--disabled` | — | 不可点/灰 |

## ② 状态→视觉映射（统一，别各写各的色）
| 语义 | 用于 | 样例令牌 |
| --- | --- | --- |
| ok 正常 | rail 完成点、放行、已闭环 | ok/ok-bg |
| warn 预警 | 当前进行、临近(免费期≤N/漂移) | warn/warn-bg |
| risk 风险 | 红灯(超期/扣留/缺证据/ISF 未申报) | risk/risk-bg |
| info 进行中 | 运行/同步 | info/brand-soft |
| 禁用/不可写 | 密封/不可点 | disabled |

## ③ 排版/间距/形态（标尺）
| 令牌 | 值 | 说明 |
| --- | --- | --- |
| 字阶 | 12 / 13 / 14(正文) / 16 / 20 / 24 | 表格12-13、正文14、H3 14、卡名16、页名20-24 |
| 数字 | tabular-nums | 金额/天数/箱号对齐 |
| 间距 | 4px 基准：4/8/12/16/24 | gap 用 grid/flex，不用散 margin |
| 圆角 | 6(小)/10(卡)/999(胶囊) | 状态胶囊圆角 |
| 阴影 | 卡片 0 1px 2px | 少量；用边框分层不过度用阴影 |
| 排版规则 | headings balance、正文≈65字符 | — |

## ④ 组件形态（同一对象同一模样）
- **状态点**：圆点 8px + 语义色（rail/红灯清单共用）。
- **状态胶囊**：文字+语义浅底（currentStatus/标记 chip）。
- **节点行**：左侧色点 + 名称 + (预计/实际) 次要行；当前=浅衬高亮+左竖条。
- **动作按钮**：主按钮=brand；已执行=disabled；危险/终态=risk 需二次确认。
- **卡头**：卡名(16) + 右侧 hint(次要 12)。
- **密封线/可选**：虚线+灰，表示不可回改/未启用。

## ⑤ 布局与层级（宏观-中观-微观）
- 页面壳：顶部(品牌+层级切换+对象身份) → 主体。
- 微观工作台 = 三栏(rail 250 / 详情弹性 / 动作 300)，窄屏折叠为纵向。
- 信息不淹没：默认亮最有信息量项，明细 hover/展开/下钻。
- 全站遵循 全局→中观→微观 下钻且带上下文。

## ⑥ 落地（代码）
- 唯一 token：`apps/web/src/style.css`（CSS 变量含明/暗/跟随系统）。
- Element Plus 覆盖：`--el-color-primary` 等指向 `--brand` 与语义，保证组件一致。
- 组件只用令牌类，禁裸色/临时十六进制（评审门禁）。
